HTML

Fundação, paredes e cômodos

Define o que existe: títulos, textos, imagens, botões, formulários, menus e seções. Também dá significado às partes para acessibilidade e buscadores.

CSS

Arquitetura visual e acabamento

Controla cores, fontes, tamanhos, espaçamentos, posições, animações e adaptação para celular ou computador.

JS

Eletricidade e mecanismos automáticos

Percebe cliques, valida formulários, realiza cálculos, busca dados e decide o que deve mudar na tela.

TS

Normas e etiquetas técnicas

Adiciona tipos ao JavaScript para deixar claro qual dado entra em cada lugar e detectar erros antes de a obra chegar ao público.

⚛

Peças pré-fabricadas

Permite criar Botão, Card, Menu e outras peças uma vez, reutilizando-as em várias telas e atualizando somente o necessário.

N

Projeto executivo e engenheiro-chefe

Trabalha sobre React e organiza rotas, páginas, servidor, cache e renderização. Coordena uma aplicação maior, mas não substitui banco, regras e hospedagem.

V

Oficina e máquinas da obra

Executa o projeto rapidamente durante o desenvolvimento e empacota os arquivos em uma versão otimizada para publicação.

NODE

Sala de máquinas

Executa JavaScript fora do navegador para processar pedidos, criar servidores, APIs, automações e tarefas internas.

API

Recepção e comunicação

Recebe uma solicitação da interface, encaminha ao setor responsável e devolve uma resposta padronizada.

SQL

Arquivo central

Guarda clientes, produtos, pedidos e pagamentos em tabelas relacionadas, com regras para manter os registros consistentes.

S

Infraestrutura interna pronta

Reúne PostgreSQL, autenticação, arquivos, APIs e tempo real. A estrutura vem pronta, mas as regras de acesso ainda precisam ser bem definidas.

GIT

Plantas, diário e histórico

Git registra as mudanças; GitHub guarda o repositório, organiza branches, revisões e colaboração. É onde a evolução do projeto fica documentada.

PW

Inspetor da obra

Abre o sistema como um usuário, clica, preenche campos e verifica se os caminhos continuam funcionando após cada alteração.

DEPLOY

Equipe de publicação e endereço público

Netlify e Vercel recebem o projeto, executam o build, distribuem os arquivos em servidores e mantêm a aplicação disponível no mesmo endereço.

O navegador continua recebendo HTML, CSS e JavaScript.

React, Next.js, Vite, TypeScript e outras ferramentas existem para construir, organizar, testar e publicar essa base com mais segurança e velocidade.
